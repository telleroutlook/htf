## 一、项目愿景

**一句话：** 把张量网络的"搭建—编译—收缩"做成类型安全的过程，且每一次收缩结果都自带严格误差界与
机器可核验证书——让计算物理里的数值结果，第一次能像证明一样被信任、被复核。

用**应用范畴论（ACT）**的弦图作为**类型安全的前端语言**，把张量网络模型的"搭建—编译—收缩"统一成
一套可组合的 Python DSL，底层用 JAX / opt_einsum 做 GPU 加速的收缩与自动微分。HTF 的区分性价值不在
"又一个张量网络库"，而在于把两样这一领域普遍缺失的东西做成一等公民：

1. **认证（Certification）：** 每一次收缩结果都携带**机器可核验的严格误差界**（键维截断 + 有限精度），
   把"变分估计"升级为**认证的上 / 下界**。
2. **结构保证（Proof-carrying structure）：** 反射正性（RP）、规范不变性、幺正性、OS-正性等物理结构，
   **由类型系统强制 + 机器核验**——"违背结构约束的网络无法编译"。

HTF 定位为张量网络 / 全息领域的"验证内核 + 难度地图"——在一个目前几乎全是未认证浮点计算的领域里，
补上认证纪律与结构保证的工具。

## 二、定位：认证模型引擎，而非世界引擎

一个诱人的隐喻是把它当作"世界引擎"：输入 → 规范化输出 → 预测。**在严格受限的意义上成立，在宏大的
意义上是范畴错误**，区别在于三层误差：

| 误差来源 | HTF 能做什么 |
|---|---|
| **(a) 数值 / 截断误差**（键维 `χ`、有限精度） | **可认证** —— 给出严格误差棒（核心贡献） |
| **(b) 离散 / 连续误差**（格点→连续、`χ→∞`） | **只能门控 / 特例界定** —— 守恒的墙，一般开放 |
| **(c) 建模误差**（这个哈密顿量真描述现实吗？） | **完全在框架之外** —— 经验物理问题 |

一个真正的"世界引擎"需同时征服 (a)(b)(c)。HTF **征服 (a)、测绘 (b)、对 (c) 保持沉默**。**认证保证的
是"这个模型的答案是 X ± ε"，不是"现实是 X"。**

还有一堵**结构性硬墙——纠缠**：张量网络对**面积律纠缠**（gapped 基态、1D、部分 2D）高效可靠，对
**体积律纠缠**（热化实时演化、高能态、有限密度费米子 = 符号问题）**本质失效**。这是信息论边界，
不是工程缺陷。

**所以最诚实、也最有价值的定位：HTF 不是"预测世界的引擎"，而是"从不谎报自己无知的引擎"。** 它带
严格保证地告诉你"给定这个模型，答案是 X ± ε，且 ε 不含建模误差，且连续极限我只能界定到这里"。一个
永不谎报不确定性的引擎，比一个自称能预测一切的引擎可信得多——而且真能造出来。

## 三、理论内核

**1. 弦图 ↔ 幺半范畴 ↔ 张量网络（成熟对应）。** `[工程]`
线（Wire）= 对象 / 向量空间；节点（Box，带 dom/cod）= 态射 / 张量；串联 `>>` = 复合；并联 `@` = 张量积；
闭环 = 求迹。这套对应是 **DisCoPy** 等已实现的标准内容；HTF 的新意在**类型安全 + 认证 + 人机工程**，
不在数学。

**2. 张量收缩与它的正则子。** `[工程]`（其中有一处必须写明的诚实）
拓扑连线映射为爱因斯坦求和，用 opt_einsum 优化收缩路径、JAX 在 GPU 上执行。**键维 `χ` 就是一个正则子
/ 截断**：连续场论的 UV 发散在这里被换成**有限键维的截断误差**，必须随 `χ→∞` 被控制。HTF 的贡献
正是把这个误差**认证化**（详见第四节 A）。

**3. MERA 与全息。** `[工程]`（小系统）/ `[研究]`（高维、规范不变）/ `[启发]`（全息）
MERA 是变分张量网络假设（disentangler + isometry 分层粗粒化），配 JAX `grad` 可做变分基态估计。
"MERA 深度 ↔ 重整化尺度 ↔ 全息额外维"是 Swingle（2009）的**启发式对应**，学界有争议，故标 `[启发]`：
一个有价值的直觉与可视化，**不是**"精确等效的 5D AdS 度规"，也**不是**"把求解全息变成画图游戏"。

## 四、核心价值轨道（区分性价值）

**A. 认证张量引擎。** `[研究]`
每次收缩携带**严格误差界**：键维截断用 radii-polynomial / Newton–Kantorovich 式验证数值（区间算术
Arb / `python-flint`），有限精度用区间误差传播。**可当证明的产出：**对具体格点哈密顿量（含小格点规范
理论）给出谱隙 / 基态能的**认证有限格点上 / 下界**——一个真定理（**不是**连续 Clay 主张）。与验证型
CAP-for-PDE 内核**共用同一套验证数值底层**。

**B. Proof-carrying Diagrams。** `[工程]` + `[研究]`
弦图不只带张量，还带**证书**：维度 / 等距 / 幺正在编译期检查；OS-Gram `min-eig ≥ 0`、精确有理数认证、
反射正性、规范不变性、`[Π_+,W]=0` 类对易性做成一等公民认证算子。**违背结构的网络无法编译或被判负。**
这是对计算物理的**形式化方法（PL）贡献**。

**C. 难度地图 / 门控实验室。** `[研究]`
系统测量一族 ansätze 的隙估计 / 关联长度 / 纠缠标度**如何随 `χ→∞`、格点→连续退化**，把它变成可比
曲线；作为张量网络物理主张的门控——**区分真效应 vs 有限尺寸 / 截断假象**。

**D. 共同底座：复现 / provenance 证书层。** `[工程]`
每个认证结果携带**可重放证书**（输入、种子、`χ`、误差界、checker 版本），状态由 checker 导出、**绝不
信任生产者自报 PASS**，可无网络无子进程重放。

## 五、扩展能力（选做子集）

由同一套"类型化弦图 + 认证张量引擎"架构自然解锁。**一个真实项目应从中选聚焦子集，而非全做**——承诺
全部本身就违背诚实边界。

- **E. 语义保持的图重写（ZX-calculus）。** `[研究]` 用可靠重写规则做**认证化简**（rewrite 层的
  proof-carrying），可参考 PyZX / DisCoPy 规则集。
- **F. 量子线路互操作。** `[工程]` / `[研究]` 弦图 ↔ 量子线路：导出 QASM、与 PyZX 互操作、NISQ 线路
  优化。
- **G. 对称适配 / 规范不变张量作为类型。** `[研究]` `U(1)` / `SU(N)` block-sparse 对称张量做成一等公民
  类型——对格点规范理论必需，对接 YM 规范不变性结构。
- **H. 开放量子系统 / CPTP。** `[工程]` 用 doubling 处理密度矩阵、混合态、CPTP，扩到耗散 / 噪声系统。
- **I. 严格双侧界。** `[研究]` 变分只给上界；补**认证下界**（Lanczos / Anderson 型），让"认证的隙"
  两侧成立——A 变严格所必需。
- **J. 可微逆向设计 / 哈密顿量学习。** `[工程]` / `[研究]` JAX autodiff → 逆问题：给定目标可观测量优化
  耦合。
- **K. 认证复现基准套件。** `[工程]` 内置已发表结果的认证复现作为能力自证。
- **L. 导出到证明助手。** `[研究]` 结构性证书导出 Lean / Coq；**已实现**（`htf/lean_export.py`：`certificate_to_lean`、`rayleigh_certificate_to_lean`、`RayleighInterval`、`LeanExporter`；每个 `sorry` 为标注的证明义务，实际形式化留给 Lean 专家）。

## 六、价值主张与受众

**最诚实的一句：** 效率提升主要不在"算得更快"（认证模式因验证开销**更慢**，浮点模式与现有工具持平），
而在**人的研究循环**——早 catch 错误、少返工、审稿可信、少走死路。

| 要做的事 | 现在（痛点） | 用 HTF 之后 | 提升在哪 |
|---|---|---|---|
| 算格点模型能隙 | 手写代码，肉眼外推，审稿反复问"收敛了吗 / 是不是假象"，指标 / 归一化易错难查 | 类型系统搭图时拦错；认证输出 `gap ∈ [a,b]`；门控标记有限-χ 假象 | 省调试 + 审稿来回 + 重跑；错误提前到编译期 |
| 要够格写进论文的严格特征值界 | 手推（慢难）或跑浮点（不算定理）；认证界需从零搭区间算术（数周） | 认证收缩是**库原语**，一次调用拿认证双侧界 | 把"数周定制严格数值编程"压成"一次调用"（**最大的一处**） |
| 判断新路线值不值得投入 | 投入数月才在墙前发现失败 | 几小时搭忠实小玩具，拿廉价严格的"过不了墙 / 在此崩" | 省数月死路（YM / RH 经验的产品化） |
| 同行核验大计算 | 重跑（昂贵）或"信作者"（复现危机） | 结果带可重放证书，几分钟独立核验 | 把"重跑数小时~数天"压成"重放几分钟" |

**三样最深的礼物：**
1. **能当定理用的认证结果**（在有限 / 局部层面）。
2. **可信、可重放的不确定性**——一个从不谎报无知的引擎。
3. **廉价而严格的"否定"与难点定位仪器**（"否定 / 边界结果"长期供给不足，这类工具能批量产出）。

**普通人可及用途（诚实，不夸大）：** 学生 / 教学（"违背物理的代码编译不过"，画图学量子力学 / 线代 /
张量）；学范畴论 / 量子计算者（弦图比指标运算直观，降门槛）；别领域需要**带保证的小型计算**但非数值
专家者；数据 / ML（可微张量 DSL）；任何需要**复核**已声称结果的人（拿证书即可重验，不必是专家）。
**但不夸大：**给普通人的是"更低门槛地做对小事、并能核验"，不是"人人预测宇宙"。

**诚实的代价：**认证模式有开销（比浮点慢）；可扩展性受纠缠边界限制（面积律行、体积律不行）。这是
一笔**纪律税**——付一点速度和适用范围，买可信、可复核、边界清楚。

## 七、展现形态与产品载体

**关键洞察：** 普通代码编译后是不透明二进制；HTF 代码"编译"后变成一张可看的图 + 一个带误差棒的结果
+ 一份证书。三层架构天然对应三种展现，不塌缩成黑盒：

| 层 | 面向谁 | 展现形态 |
|---|---|---|
| **① 拓扑符号层**（你写的 `>>` / `@`） | 人 | **一张弦图** + 类型检查报告（"维度 ✓、连通 ✓、等距 ✓"） |
| **② 函子翻译层** | 机器 / 调试 | **中间表示（IR）**：带爱因斯坦索引的计算图 + 收缩路径 + 复杂度 / 内存估计 |
| **③ 张量引擎层** | 结果 | **数 / 张量 + 认证误差区间**（如 `gap ∈ [0.412, 0.418]`）+ 图表 + 证书 |

**执行后的输出长相：**
- 认证结果 `X ± ε`
- 难度地图 / 收敛曲线（一眼辨真效应 vs 假象）
- MERA 几何可视化（`[启发]` 级，标注为类比，非精确对应）
- 可重放证书（人读 + 机读）
- 结构报告（如"RP ✓、规范 ✓"，或"OS-正性判负，问题出在此处"）

**产品载体（由浅入深）：**
1. **Python 库**（`import htf`）——最基础的调用方式。
2. **Notebook 集成**——图内联、结果带误差棒内联，最日常的使用场景。
3. **可视化图编辑器**——拖拽画图、实时类型检查，最适合教学与非专家。
4. **命令行 checker**（proofctl 式）——输出认证判决 + 证书，最适合审稿 / CI / 可复现流水线。
5. **Web playground**——粘图 → 认证结果 + 可分享证书。
6. **导出**——TikZ / LaTeX 图、QASM、证书文件，与 quimb / ITensor 互操作。
7. **Agent-可驱动的 CLI / MCP 服务**——见下，让普通人用自然语言操作。

### 7. Agent-可驱动的 CLI：让非专家用自然语言操作

**这是"普通人可及"的真正落地路径**：非专家不写范畴论代码，而是**用自然语言对一个 LLM agent 提问**，
agent 把意图翻译成结构化 CLI 命令、执行、再把认证结果用自然语言解释回去。为此 CLI 必须**为 agent 而
设计**（`[工程]`）：

- **结构化、可组合的子命令**（动词）：`htf build` / `typecheck` / `contract` / `certify` / `verify` /
  `plot`——agent 能像搭积木一样组合。
- **机器可读 I/O（JSON 进 / 出）**：结果、误差界 `X ± ε`、结构判决、证书路径都是结构化数据，agent 能
  解析，而不是靠解析人类文本。
- **自描述 / 可发现**：`htf --help` + 命令的 JSON schema（像工具调用的 schema），agent 无需猜测就知道
  工具表面；可再包一层 **MCP 服务**，让 agent 直接连接调用。
- **确定性、可重放**：证书 + 固定种子 → agent（或任何人）能复现、能核验。
- **错误即结构化数据**：类型 / 维度 / 结构违反以结构化形式返回（"网络在 box X 违反反射正性"），agent
  能转成自然语言解释给用户。
- **诚实不确定性随输出传播**：CLI 强制返回 `X ± ε` + 等级 + 判决，**agent 因此被证书约束、无法丢掉
  误差棒或夸大**——"从不谎报无知"的性质**透过 agent 层一直传到自然语言**。

**一句话闭环：** 普通人说人话 → agent 译成 `htf` 命令 → 认证内核算出带误差棒的结果 + 证书 → agent 用
人话解释（且不敢夸大，因为证书钉死了边界）。**agent 是可及性层，不是正确性层**——正确性来自底层认证
CLI；且**建模误差 (c) 仍在人这一侧**：agent 帮你操作工具，不替你验证"这个模型是否描述现实"。

**这正是这个工具展现形态本身的价值：**你看得见结构、查得到过程、验得了结论——可信性不是声明出来
的，而是格式本身带出来的。

### 8. 可视化前端与友好度北极星（Scratch 直觉）

把可视化做到极致，HTF 的形态趋近 **Scratch**——但这句话需要拆成"能达到的"和"达不到的"两半，才诚实。

**为什么 Scratch 是对的类比。** Scratch 的魔法核心是"**积木只能拼在合法处，所以做不出语法错误**"；
HTF 的**类型安全弦图**是同一件事——"维度不匹配的线连不上 / 编译不过"= 你**画不出违背物理约束的图**。
这是**同构**，不是比喻。已有先例证明这类领域的**界面级友好度可达**：IBM Quantum Composer、Quirk
（拖拽式量子线路搭建器），就是"量子线路的 Scratch"。

**技术栈能不能达到？——把两件正交的事分开。** 计算栈（Python / JAX / DisCoPy）是**后端**，既不提供也不
阻碍友好度；友好度是**前端**问题。纯文本 DSL 确实不 Scratch-友好，但**架构里的"类型检查符号层"恰是
Scratch 式吸附（snapping）所需的底座**。所以不是"栈达不到"，而是**前端还没建**——这是一块独立、可达、
但不小的工程（好的可视化编辑器是数月量级）。**结论：界面级友好度可达，栈不构成障碍。**

**两条诚实的天花板。**
1. **界面友好 ≠ 领域友好（本质区别）。** Scratch 对小孩友好，是因为**界面 + 领域**同时可及（"让猫动"
   本身就直观）。HTF 能做到**界面友好**，但**领域是内禀专家级的**——再完美的 UI 也无法让"反射正性 /
   键维 χ"像"让猫动"一样对新手直观。故天花板是"**内禀专家领域的 Scratch 式友好界面**"、"**教概念极好**"，
   **不是**"让完全的小白做研究"。这个限制是根本的，不是栈的问题。
2. **视觉范式是节点图（node graph），不是 Scratch 的竖直积木栈。** 弦图是**二维 / 拓扑**结构（2D 布线、
   伴随、非平面连接），线性积木栈表达不了。对的参照物是**节点图编辑器**（如 React Flow；或 Blender 几何
   节点、Max/MSP、LabVIEW、虚幻蓝图这类）+ 前述量子线路搭建器，用"端口类型匹配才能连"实现"连不错"。

**两条互补的友好度路线。** 对真正的小白，比拖积木更友好的可能是**对话**：
- **可视化路线**（看得见、拖得动）——适合学习者、教学、喜欢动手看的人；
- **对话路线**（直接问 agent，见 §7.7）——适合完全不懂内部结构、只想要答案的人，他连积木都不用理解。

**北极星（一句话）：** 当前栈**不排斥** Scratch 级的**界面**友好度（那是一块待建的节点图前端，可达）；
但**没有任何 UI 能达到 Scratch 级的领域友好度**，因为物理内禀是专家级的——对真正的小白，**对话式 agent
路线**比拖积木更现实。可视化前端因此是**教学 / 学习 / 探索**的强力形态，而非"人人做研究"的许诺。

## 八、系统架构与技术栈

**三层延迟执行架构**（与第七节的三层展现一一对应）：
1. **拓扑符号层**——`Wire` / `Box` / `Diagram`，只做类型、连通性、结构检查。
2. **函子翻译层**——`TensorFunctor` 把弦图编译成带爱因斯坦索引的计算图。
3. **张量引擎层**——双模式：**浮点模式**（`opt_einsum` + JAX，快速探索）／**认证模式**（区间算术，
   带严格误差界）。

**技术栈：**
- 语言：Python 3.10+
- 范畴论后端：参考 DisCoPy 的实现
- 张量收缩：JAX + `opt_einsum`（可选接入 quimb / TensorNetwork）
- 认证数值：Arb / `python-flint`（区间算术）
- 拓扑存储：自定义 DAG 或 NetworkX

## 九、研发路线图

**Phase 1 — 类型安全的弦图 "Hello World"**（约 2 周）`[工程]`
`Wire` / `Box` + `>>` / `@`；`eval()` 跑通"向量→矩阵演化→向量"；验证是合法的范畴论态射。（本质是重写
一个轻量版 DisCoPy。）

**Phase 2 — 一维模型 + 认证模式起步**（约 1 个月）`[工程]`
Box 串联一维格点算子；**唯一里程碑 = 正确性**（与传统数值解一致）。诚实说明：`DiffBox` 本身就是差分 /
谱算子的张量表示，价值在可组合、类型安全，**不是**"抛弃有限差分"；稳定性取决于具体格式，框架本身
中立。本阶段引入认证模式，给出区间误差界。

**Phase 3 — MERA 变分 + 首个认证界 + proof-carrying**（约 2 个月）`[工程]` / `[研究]`
MERA 树（严格等距）+ JAX `grad` 变分基态；对小系统给出首个认证谱隙界（对应第四节 A）；首个结构核验
（对应第四节 B，如机器核验转移矩阵网络的反射正性）。"第 5 维涌现"作为 `[启发]` 级可视化呈现。

**Phase 4 — 认证有限格点物理**（核心价值目标；开放式里程碑，无法给出可信的固定工期）`[研究]` + `[OUT]`
**可做：**对格点哈密顿量（含小格点规范理论）给出谱隙的认证有限格点上 / 下界，在严格误差控制下做
`χ→∞` 外推，机器核验 OS-正性 / 规范不变性；产出认证的有限格点定理 + 难度地图。
**明确不声称（`[OUT]`）：**不是连续 Yang–Mills 质量隙的证明（MERA 够不到 4D 连续非微扰隙；4D + 规范
不变张量网络本身仍是开放问题）。

## 十、诚实边界

### 适用范围与边界（工具的诚实自陈）
**有限 / 变分 / 张量方法擅长"认证有限局部结构 + 测绘 + 门控"，但不独自跨越连续墙；正则化（键维 `χ`
截断）不等于解决连续问题；"读出"一个谱隙不等于"证明"它。** 张量网络把困难从"连续 UV 发散"**搬到**
"`χ→∞` 与格点→连续的一致控制"。HTF 的价值正建立在诚实承认这条边界之上——把力气放在**有限 / 局部层
的认证**与**工具**，而非声称跨过了这堵墙。

### 与现有工具的诚实定位
弦图→张量收缩内核 = DisCoPy 已实现；MERA-全息 = Swingle 等已提出；张量网络原语 = quimb /
TensorNetwork 已有；图重写 = PyZX 已有。**HTF 的真正新意 = 认证张量引擎 + proof-carrying diagrams +
类型安全 DSL 的集成**——把"验证数值 / 结构证书"这一层带进尚无认证纪律的领域，而非新数学或新物理。

### 该项目会 / 不会声称
**会：**类型安全、可组合、可复现的弦图 / 张量网络 DSL；带**认证误差界**的张量引擎；对格点模型（含小
格点规范理论）的**认证有限格点谱隙上 / 下界**；结构性质（RP / 规范不变 / OS-正性）的**机器核验**；
`χ→∞` / 连续退化的定量难度地图；可重放证书。

**不会（硬边界）：**不声称免疫 UV 发散（那是键维正则化）；不声称证明或逼近连续 Yang–Mills 质量隙
（`[OUT]`）；不把 MERA↔AdS 启发式类比说成已实现的全息求解；不声称"抛弃 PDE / 绝对稳定性"；不声称是
预测现实的"世界引擎"（它是认证模型引擎，对建模误差沉默、受纠缠边界限制）。

*工程部分（Phase 1–3）可行且有价值；核心价值轨道（认证 + proof-carrying + 难度地图）落在"计算能当
证明"的有限 / 局部区，是这一领域真正缺失、且作者经验独特适配的贡献；其证明层难点（连续极限、
`χ→∞` 一致控制、4D 规范不变性）是守恒的、开放的，不由本框架的存在而消除。*
